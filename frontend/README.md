# Smart Bin · Rice Vendo — Frontend

Next.js kiosk terminal and admin dashboard. The backend is a separate app; see `backend/README.md`.

## Clone and Setup

Clone the repository and open it in VS Code:

```bash
git clone <url>
cd Smart_Trash_Bin
code .
```

Then install and run the frontend:

```bash
cd frontend
npm install
npm run dev
```

Wait for the dependencies to install, then open [http://localhost:3000](http://localhost:3000)
in your browser.
